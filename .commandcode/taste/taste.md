# Taste

- Prefers reusable design-guideline / design-system skills to stay general-purpose: project-specific artifacts (e.g., a book cover image/asset) don't belong in them, only general design tokens and rules. Confidence: 0.7
- Dislikes pill-shaped / fully-rounded buttons that sit inline next to input fields ("looks weird, doesn't fit well with the text box"); wants the button's corner radius to match the adjacent input (e.g., rounded-lg) so the two read as one control. Standalone buttons not paired with an input can stay pill-shaped. Confidence: 0.8
